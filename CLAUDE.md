# Project Context for Claude Code

This project uses the OES (Objective Execution System) workflow.

## Workflow

- Story/requirements live in `.oes/PROJECT.md`
- Phased plan lives in `.oes/ROADMAP.md`
- Constraints live in `.oes/CONSTRAINTS.md`
- Session state lives in `.oes/.local/STATE.md`
- Config lives in `.oes/.local/config.json`

Use `/oes:build` to begin or continue work, `/oes:resume` to pick up after a break, and `/oes:ship` to complete the story.
